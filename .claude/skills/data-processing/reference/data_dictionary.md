# Data dictionary

[Tiếng Việt](data_dictionary.vi.md)

What each column means: type, unit, valid values. The scripts read the `yaml` block below; the text
around it is for people.

> This is the configuration of the retail orders sample (`examples/ban_hang/`). When you start with your
> own data, ask Claude to follow section B of SKILL.md and this yaml block is replaced with your columns.

## How to declare a column

| Key | Meaning |
|---|---|
| `source_names` | Column names that may appear in the source file (case and extra spaces are ignored) |
| `type` | `string`, `int`, `float`, `money`, `percent`, `date`, `bool`. `money` columns are reconciled in layer 2. `percent` is stored as 0..1 and accepts "15%" or 0.15; a bare 15 is treated as ambiguous |
| `number_format` | Number format for this column only, e.g. `{decimal: ".", thousands: ","}` for US style |
| `map` | Normalise text values before checks, e.g. `{"Viet Nam": VN, "vn": VN}` (case-insensitive) |
| `meaning`, `unit` | Plain words, so the next person understands |
| `required` | `true` means a blank cell drops the row during clean |
| `key` | `true` if the column is (part of) the key; layer 1 blocks on duplicates |
| `min`, `max`, `non_negative` | Valid range, layer 3 warns when outside |
| `allowed_values` | List of allowed values, layer 3 warns on others |
| `max_blank_ratio` | Blank threshold for this column (overrides the default in validation_rules) |
| `source: computed` | Column created by transform.py, not in the source file |
| `skip: true` | Column exists in the source but is intentionally not used |
| `status` | `confirmed` or `unclear`. Any `unclear` column blocks the run |

Vietnamese key names (`ten_goc`, `kieu`, `bat_buoc`...) also work, see `data_dictionary.vi.md`.

```yaml
columns:
  ma_don:
    source_names: ["Mã đơn", "Ma don", "Order ID"]
    type: string
    meaning: Order ID generated by the sales system
    required: true
    key: true
    status: confirmed

  ngay_dat:
    source_names: ["Ngày đặt", "Order date"]
    type: date
    meaning: Date the customer placed the order
    required: true
    min: 2020-01-01
    status: confirmed

  ngay_giao:
    source_names: ["Ngày giao", "Delivery date"]
    type: date
    meaning: Date delivered, blank if not delivered yet
    max_blank_ratio: 0.3
    status: confirmed

  ma_khach:
    source_names: ["Mã KH", "Mã khách hàng", "Customer ID"]
    type: string
    meaning: Customer ID
    required: true
    status: confirmed

  san_pham:
    source_names: ["Sản phẩm", "Product"]
    type: string
    meaning: Product name
    status: confirmed

  so_luong:
    source_names: ["SL", "Số lượng", "Quantity"]
    type: int
    unit: pieces
    required: true
    min: 1
    max: 1000
    status: confirmed

  don_gia:
    source_names: ["Đơn giá", "Unit price"]
    type: money
    unit: VND
    non_negative: true
    status: confirmed

  thanh_tien:
    source_names: ["Thành tiền", "Amount"]
    type: money
    unit: VND
    meaning: Amount the customer paid for the line, after discount
    required: true
    non_negative: true
    status: confirmed

  kenh:
    source_names: ["Kênh bán", "Channel"]
    type: string
    allowed_values: ["Cửa hàng", "Website", "Sàn TMĐT"]
    status: confirmed

  ghi_chu_noi_bo:
    source_names: ["Ghi chú nội bộ", "Internal note"]
    skip: true
    meaning: Free-text staff note, not used for reporting

  # Columns created by transform.py
  thang:
    source: computed
    type: string
    meaning: Order month as YYYY-MM
    status: confirmed

  chenh_lech_thanh_tien:
    source: computed
    type: float
    unit: VND
    meaning: thanh_tien minus so_luong x don_gia. Non-zero means a discount or a typing error
    min: 0
    max: 0
    max_blank_ratio: 0.1
    status: confirmed
```
