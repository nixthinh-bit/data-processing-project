# Sample: retail orders

[Tiếng Việt](#bộ-mẫu-đơn-hàng-bán-lẻ)

`don_hang_2026-10-01.xlsx` holds 126 fictional order lines, generated by `tao_du_lieu_mau.py`. This is the
default configuration after cloning, so copy the Excel file into `data/raw/` and run.
`data_dictionary.md` and `validation_rules.md` are in English, the `.vi.md` files are the same in Vietnamese.

Planted problems: a blank row, an order without an ID, a quantity typed as text ("hai"), an amount typed as
text ("32.000"), delivery before order date, an unknown channel ("Facebook"), an amount that differs from
quantity x unit price.

Expected result: 123 rows kept, 3 excluded with reasons, layers 1 and 2 pass, 3 warnings in layer 3.

## Bộ mẫu: đơn hàng bán lẻ

File `don_hang_2026-10-01.xlsx` có 126 dòng đơn hàng hư cấu, sinh bằng `tao_du_lieu_mau.py`. Đây là cấu
hình mặc định khi mới clone, nên chỉ cần chép file Excel vào `data/raw/` rồi chạy. Cấu hình tiếng Việt là
các file `.vi.md`.

Lỗi cài sẵn: một dòng trống, một đơn thiếu mã, số lượng ghi bằng chữ ("hai"), số tiền dạng chữ ("32.000"),
ngày giao trước ngày đặt, kênh bán lạ ("Facebook"), thành tiền lệch số lượng x đơn giá.

Kết quả mong đợi: giữ 123 dòng, loại 3 dòng có lý do, tầng 1 và 2 đạt, 3 cảnh báo ở tầng 3.
